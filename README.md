# ChessMind

Chess puzzle app built with React and Vite, with a standalone chess companion.

## Run locally

Install Node.js and npm, then run:

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The standalone companion is in `companion/`; open `companion/index.html` in a browser.
